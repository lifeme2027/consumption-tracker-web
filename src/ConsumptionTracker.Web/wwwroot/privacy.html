这是什么

一个纯记录工具：记录日常消费和用药（名称、价格、数量、分类、日期、批次、用药人、剂量、备注）。不涉及任何支付、转账或交易，也不会读取你的钱包余额。

两种模式：默认本地，登录才上云

页面顶部会标明当前是本地模式还是云端模式。不登录也能使用全部功能；登录 Kaspa 钱包是可选的。

本地模式（默认，无需登录）

  • 数据只在你的浏览器里（浏览器的 IndexedDB），不会发送到服务器：本地模式下登记、查看、修改、删除、统计、导入导出都在浏览器内完成，页面不会向本站提交任何记录。
  • 清除浏览器数据、使用无痕窗口、换浏览器或换设备，数据都会丢失，本站也无法帮你找回。请定期导出备份（“数据”页）。
  • 同一台电脑上能打开这个浏览器的人可以看到这些数据；请不要在公用电脑上使用，或用完后在“数据”页删除。
  • 条码记忆：保存带条码的记录时，浏览器会在本机 IndexedDB 里记住该条码对应的名称、分类和最近一次单价；下次登记时输入或扫描同一条码，会自动带出这些内容（都可以修改）。这份记忆只在你的浏览器里，不发送到服务器；“数据”页的一键删除会把它一并清除，导出的 JSON 备份里也会带上它。
  • 用药名称、用药人、剂量、备注属于健康相关的敏感信息。本地模式下它们只存在你的浏览器里，没有登录、没有会话、本站没有任何副本；你自己导出的 JSON / CSV 文件未加密，请妥善保管。
  • 本地删除：“数据”页的一键删除会把这些数据从浏览器的 IndexedDB 中删掉。但浏览器底层的存储引擎和磁盘可能在一段时间内仍保留已删除内容的残片，我们无法控制；你已经下载的导出文件、其他设备或其他浏览器里的数据，也不会因此被删除。
  • 本地模式下本站没有账户、没有会话，因此也没有会话有效期或服务器备份的问题；打开页面只会请求页面文件本身（见下面“服务器访问日志”）。

云端模式（登录 Kaspa 钱包后，可选）

  • 登录后，记录保存在本站服务器的数据库中，不对外分享、不出售、不用于广告，也没有任何第三方统计或分析脚本。
  • 数据按 Kaspa 地址隔离：每个地址只能读写自己名下的数据，服务端对每次读写都校验归属。
  • 数据存在服务器上，没有端到端加密：服务器端可以读取明文数据，服务器管理员在技术上也能访问数据库文件。请不要在备注等字段里写入你不希望存放在服务器上的敏感信息。
  • 地址不等于匿名：你的 Kaspa 地址本身是公开的链上标识，本站也会保存它来区分账户；本站不承诺匿名。
  • 登录后不会自动同步：本地数据与云端数据各自独立。只有你在“数据”页点“上传本地数据到账户”或“从账户下载到本地”（每次都会确认并说明合并/覆盖）时，数据才会在两者之间搬运。
  • 点“退出云端”会作废会话并回到本地模式，本地数据保持原样。
  • 用药名称、用药人、剂量、备注属于健康相关的敏感信息。云端模式下这些内容会以明文存放在服务器上（见上，没有端到端加密）。如果你不愿意把这类信息放在服务器上，请使用本地模式，或不要填写这些字段。

云端模式：会话有效期

  • 登录后的会话固定 12 小时有效（不会因为你继续使用而自动延长），到期需要重新用钱包签名登录。
  • 点“退出云端”会立即作废会话；会话令牌在服务器库里只保存哈希，不保存明文令牌。
  • “一键删除全部数据”不会使现有会话失效（会话与数据是两件事）；要结束会话请点“退出云端”。

云端模式：删除到底做了什么

“一键删除”和单条删除是真的删除，但我们不夸大它的效果。准确地说：

  • secure_delete：数据库开启了 SQLite 的 secure_delete，被删记录的内容会在数据库页里被擦写为零，而不是仅仅标记为空闲。
  • checkpoint：一键删除完成后，服务器立即把预写日志（WAL）合并回主库并截断，已删内容不会继续留在日志文件里；此外服务器每小时做一次同样的合并（单条删除留在日志里的内容最长约一小时内被清理）。
  • 定期 VACUUM：服务器约每 24 小时对数据库做一次 VACUUM，重写整个库文件、丢弃空闲页，使文件不再保留旧页面。
  • 不会被删除的东西：服务器上已经存在的备份副本（含删除之前的明文数据库拷贝）不会因为你点删除而被改动；你已经下载的导出文件，以及磁盘底层（固态硬盘磨损均衡、系统快照等）我们无法控制的残留，也不会被删除。因此删除的效果不是绝对的，我们不做这样的承诺。

云端模式：服务器备份与保留

  • 管理员可能会备份服务器上的数据库文件，备份是明文的（与数据库本身一样，没有端到端加密）。
  • 备份和旧备份由管理员手动清理，我们不承诺自动清理，也不承诺具体的保留期限。所以你在云端删除的数据，仍可能留在已经存在的旧备份里，直到管理员把这些备份删掉；程序不会替你删除它们。
  • 备份只用于灾难恢复，不会用于其他用途，也不会分享给第三方。

服务器访问日志（IIS 日志）

  • 无论哪种模式，只要打开本站页面，服务器前面的 IIS 就会按常规写访问日志：时间、你的 IP 地址、请求的网址（路径）、状态码、浏览器 User-Agent等。
  • 日志不含你的记录内容（名称、备注、用药人、剂量等）：这些通过请求体提交，关键词搜索也用请求体，不出现在网址里。但日志能显示“某个 IP 在某个时间访问过本站 / 调用过某个接口”。
  • IIS 日志同样由管理员手动清理，不承诺自动清理，也不承诺具体的保留期限。
  • 本地模式下，页面本身不会向本站提交记录，日志里只会有加载页面文件的请求。

登录与密钥

  • 登录时只需用你的 Kaspa 钱包对服务器给出的一次性消息做签名，用于证明你拥有该地址。消息包含随机 Nonce 和时间，只能使用一次，几分钟内有效。
  • 这个签名不会产生链上交易，也不会授权转账。
  • 本站永远不会向你索要私钥或助记词。如果有人以本站名义索要，请勿提供。
  • 登录成功后，服务器下发一个有效期有限的 HttpOnly 会话 Cookie；退出登录会立即作废它。

应用日志

本站应用自己的日志只记警告及以上级别，且不记录记录内容（名称、备注、用药人、剂量、批次等）。关键词搜索使用请求体提交，不会出现在网址里。IIS 访问日志见上文。

你的控制权

  • 一键导出全部数据：在“数据”页下载 JSON / CSV（两种模式都可用，文件未加密，请妥善保管）。
  • 一键删除全部数据：在“数据”页删除当前模式下的全部记录（需要二次确认；本页不提供撤销）。删除的真实含义和备份保留期见上文“本地删除”与“云端模式：删除到底做了什么”。

其他

页面不加载任何外部脚本、字体或统计服务，浏览器内容安全策略（CSP）只允许连接本站（本地模式下页面连本站也不会提交记录）。扫码使用随站点一起提供的本地组件，相机画面只在你的浏览器内处理，不会上传。
