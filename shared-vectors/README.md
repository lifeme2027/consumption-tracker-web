# 三端共享测试向量

桌面、网站、手机三端必须对同一输入给出同一结果。两个仓库（consumption-tracker-desktop / consumption-tracker-web）里这个目录的内容保持**逐字节相同**。

- `money.json`：`[{"input":"1.005","cents":101}, ...]`。`cents` 为 `null` 表示该输入必须被**拒绝**（负数、空、非法、歧义）。
- `quantity.json`：`[{"input":"2.5","quantity":"2.5"}, ...]`。`quantity` 为十进制字符串（比较时按数值，`"1.50"` 与 1.5 相等）；`null` 表示拒绝。
- `csv-text.json`：CSV 文本单元格防公式注入的导出/导入向量（`text` ↔ `cell`），随第 ② 项加入。

## 金额规则（价格字符串 → 分）
1. 十进制字符串精确解析，**不经过二进制浮点**；超过两位小数按**四舍五入半进位 (half-up)** 到分（只看第 3 位小数：≥5 进位）。
2. 语法：可选前导 `¥`/`￥`（其后允许空白）；然后是 ASCII 数字，可选 `.` 加 1 位以上数字。拒绝：空、负号/正号、指数、`5.`、`.5`、内部空白、全角数字、第二个小数点。首尾空白忽略。
3. 逗号：只接受严格千分位——首组 1–3 位、其后每组恰好 3 位；且仅有一个逗号分组时必须带小数点（`1,234.50` 接受，`1,234` 因可能是 1.234 而拒绝，`1,234,567` 接受）。`12,5`、`1,5`、`1,23` 一律拒绝，提示「请用小数点」。全角逗号 `，` 拒绝。
4. 价格上限 1,000,000,000.00 元（含）。

## 数量规则
大于 0 的十进制，最多 6 位小数，≤ 1,000,000；不接受逗号、`.5`、`5.`、指数。保存/导出时保留输入的全部小数位（去掉末尾多余 0 不影响数值）。

## 金额（行合计）
`round_half_up(priceCents × quantity)`，用十进制/整数运算，不用浮点。例：777 分 × 2.5 = 1943 分。
